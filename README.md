# Text Generation Portal

This project is a simple text generation portal built with a NanoGPT-based character-level language model.

The model was trained using cleaned Twitter text data that was prepared from a previous Twitter corpus cleaning task. The main goal of this project is to show the full workflow from raw Twitter text cleaning to text generation through a simple web portal.

---

## Project Overview

This project has two main parts:

1. **Twitter corpus cleaning**
   - Raw or corrupted Twitter text was cleaned and prepared.
   - The final cleaned text file was saved as `cleaned_output.txt`.

2. **Twitter text generation portal**
   - The cleaned Twitter text was used as the input dataset for a NanoGPT-based model.
   - The model learns character-level patterns from the Twitter-style text.
   - A simple portal allows users to enter a prompt and generate Twitter-style text completion.

---

## Data Preparation Workflow

The Twitter data was first cleaned in the `twitter_corpus_cleaning` folder.

The most important file from this step is:

```text
twitter_corpus_cleaning/twitter_cleaning_deliverable/cleaned_output.txt
```

This cleaned output file was then copied into the NanoGPT data folder as:

```text
data/twitter/input.txt
```

In other words, the cleaned Twitter corpus became the input text used for training the text generation model.

The overall data flow is:

```text
corrupt_twitter_corpus.txt
        ↓
twitter cleaning script
        ↓
cleaned_output.txt
        ↓
data/twitter/input.txt
        ↓
prepare.py
        ↓
train.bin / val.bin / meta.pkl
        ↓
train.py
        ↓
out_twitter/ckpt.pt
        ↓
text generation portal demo
```

## Important Files

### Twitter Cleaning Files

- `corrupt_twitter_corpus.txt`  
  Original corrupted Twitter text data.

- `twitter cleaning.py`  
  Python script used to clean the Twitter corpus.

- `twitter_cleaning_deliverable/cleaned_output.txt`  
  Final cleaned Twitter text. This file was used as the source text for the text generation model.

---

### Model and Portal Files

- `data/twitter/input.txt`  
  Input text used to train the NanoGPT-based model. This file comes from `cleaned_output.txt`.

- `data/twitter/prepare.py`  
  Converts `input.txt` into binary training files.

- `data/twitter/train.bin` and `data/twitter/val.bin`  
  Prepared training and validation data files.

- `data/twitter/meta.pkl`  
  Metadata file containing vocabulary information for character-level modeling.

- `train.py`  
  Trains the NanoGPT-based model.

- `sample.py`  
  Generates sample text from the trained model.

- `app.py`  
  Runs the text generation portal.

- `index.html`  
  Front-end page for the portal interface.

- `sample_output.txt`  
  Example output generated by the trained model.

## How to Reproduce the Workflow

### 1. Prepare the Twitter input data

The cleaned Twitter data is already included as:

```text
data/twitter/input.txt
```

This file was created from:

```text
twitter_corpus_cleaning/twitter_cleaning_deliverable/cleaned_output.txt
```

---

### 2. Prepare binary training files

Run:

```bash
python data/twitter/prepare.py
```

This creates:

```text
data/twitter/train.bin
data/twitter/val.bin
data/twitter/meta.pkl
```

---

### 3. Train the model

Run:

```bash
python train.py
```

After training, the model checkpoint will be saved in:

```text
out_twitter/ckpt.pt
```

---

### 4. Generate sample text

Run:

```bash
python sample.py
```

This uses the trained checkpoint to generate Twitter-style text output.

---

### 5. Run the text generation portal

Run:

```bash
python app.py
```

After running the command, the terminal will display a local server URL.

For example:

```text
http://127.0.0.1:5000
```

or:

```text
http://localhost:5000
```

Open the displayed URL in your browser to view the text generation portal.

The portal allows users to enter a prompt and generate Twitter-style text based on the trained NanoGPT model.

---

## Demo Description

After running `python app.py`, open the local URL shown in the terminal to access the portal in a web browser.

In the demo, users can either type their own prompt or use a quick starter prompt.

For example:

```text
Today I feel
```

or:

```text
like staying home because
```

After clicking the completion button, the portal generates text based on the cleaned Twitter dataset.

Because this model was trained on a relatively small Twitter dataset, the generated text may not always be grammatically perfect. However, it demonstrates how cleaned text data can be used to train a small language model and build a simple text generation interface.

## Summary

This project shows an end-to-end text generation workflow:

```text
Twitter data cleaning
→ cleaned text preparation
→ NanoGPT training data generation
→ model training
→ text generation
→ web portal demo
```

The key connection is that the cleaned Twitter output from the data cleaning step was reused as the input text for the NanoGPT-based text generation portal.
